# Tasks live on the virta board

This repo's work is tracked on the **virta** task board, under the project `tosijs-platform`
(<https://virta.tosijs.net/host/#?virta.scope=tosijs-platform>). The board is where tasks are
filed, triaged, worked on and closed. Agents in this repo see it through `virta brief`, which
the SessionStart hook runs, and through the `virta` CLI or its MCP server.

This file is only a pointer, written as prose on purpose: a list item here would be imported
as a task. The previous contents (the task lists, and the design notes and findings that sat
among them) are archived as-is in `docs/archive/TODO-2026-09-26.md`. Every item was imported
onto the board on 2026-09-26 with its full text and a link back to its source line.

Moving a task to `ready` is the owner's go-ahead; agents file work into the backlog.
