## Follow-ups

### -> this repo's `TODO.md`

- [ ] **`/esm` still has the cross-credential cache problem on loewald.com** (security, **verified**, minor, predates the patch). `functions/src/esm.ts:51-55` calls `getDoc(req, …)` with the caller's real roles (`module.ts`: public callers see only modules tagged `public`; developers see everything). It sends errors and successes with no Cache-Control, and firebase.json rewrites `/esm/*` through Hosting. So an anonymous error can be served to a developer. The reverse is also plausible: a developer's Bearer 200 containing private module source could be served to anonymous visitors. Practical exposure is low, because `<tosi-esm>` uses `import()` and sends no Authorization header. Fix: `getDoc(asPublicRequest(req), …)` (the "SSR is public" rule), plus `noStore(res)` or `fail()` on the error branch.
- [ ] **Route the SSR error paths through `fail()`/`notFound()` or `noStore()`** (correctness/blast-radius, verified in part). These are `stored.ts:50/58/75/110/116`, `prefetch.ts:137`, `sitemap.ts:32/41` and `cached-query.ts:54/80/86/99`. The risk is availability, not a leak: a transient 5xx, or a 404 for a file requested before its upload finished, stays cached for 600 s. There is also a specific trap in `stored.ts`. Line 104 sets `public, max-age=3600` before streaming, so a stream failure at line 110 sends a 500 explicitly marked cacheable for an hour.
- [ ] **Derive the no-store guard from the `index.ts` exports** (blast-radius, unverified, minor). `endpoint-wiring.test.ts:386` checks a hand-written `PLATFORM` list of eight. Instead, make every exported endpoint either call `noStore()` before `optionsResponse()` or sit on an explicit, commented allowlist of CDN-cacheable endpoints (prefetch, prefetchData, sitemap, esm, stored, cachedQuery). Optionally, move the policy into one `platformRequest(onRequest)` wrapper so it lives in a single place, like the universal stored-ajs endpoint the roadmap plans.
- [ ] **Add behavioural #27 tests** (correctness + security nits, unverified, deduped). The current tests regex the source (`endpoint-wiring.test.ts:396/406`), so they break when code is reformatted and still pass if the call sits in dead code or is later overridden. Use the spy-`res` pattern from `errors.test.ts`: call `optionsResponse` with a disallowed method (403) and with the rate limit exhausted (429), call each handler on one error branch, and assert `no-store`.
- [ ] **Audit `gen.ts` for the same class of bug** (completeness gap). It accepts GET, depends on credentials (403 at `gen.ts:166`), and has no Cache-Control on success or error. It is safe today only because no rewrite on loewald.com points at it. Write that down, or add `noStore`. Also settle what ships for gen: tsconfig excludes `src/gen.ts`, yet `lib/src/gen.js` was rebuilt and `index.ts` exports `gen`. CLAUDE.md's statement that "firebase.json ignores gen.ts" is stale, because the current ignore list has no gen entry. That makes it a doc candidate to surface, not to edit unprompted.
- [ ] **Re-check the authorize consent page's `public, max-age=3600`** (completeness gap). `authorize-endpoint.ts:87` overrides the no-store set earlier. Confirm the page can't vary by caller or request id (selfUrl or query-string content). If it can, it would be shared by URL for an hour.
- [ ] **Add a site-facing migration note** (completeness gap). On loewald.com, the SSR endpoints' `optionsResponse` 429/403 responses, and the OPTIONS 204 on the eight platform endpoints, are now `no-store`. That is harmless: `Access-Control-Max-Age: 3600` still covers browser preflight caching. But neither the commit nor the CHANGELOG mentions it.
- [ ] **Package size in preflight** (efficiency nit, carried over, already `TODO.md:179`). Have preflight print packed/unpacked size and the change since the last tag, so gate 1 closes on a number.
- [ ] **Suite timing baseline** (efficiency nit, carried over, from `reviews/0.2.0-beta.3-log-integrity.md:179`). Store per-suite timings and have preflight print the change. This run: 711 tests in 4.19 s against 4.17 s; `tsc --noEmit` 3.0 s.
