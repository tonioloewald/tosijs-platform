# Upstream asks live on the virta board

Findings this repo depends on in other projects are tracked on the virta board, in the
`tosijs-platform` project. If the upstream project is itself on the board, they are filed in
that project. A repo that is not on the board still gets a GitHub issue, because filing a board
task for it would enroll it. The previous contents are archived in
`docs/archive/UPSTREAM-2026-09-26.md`.
